Project 4: Herbal Navigator

Overview: A desktop application that serves as both a medication regimen viewer and a symptom checker for herbal remedies. It allows users to select a disease or illness, view detailed herbal remedy information from local CSV/JSON data, and access additional details via deep searches.

Key Features:

  • Interactive Data Lookup: Browse a hierarchical view of diseases, treatments, and medications.
  • Deep Search: Autocomplete search bar with Google suggestions and secure deep web searches (using Tor for anonymity).
  • Dynamic Image Grid: Retrieves and organizes images from Google.
  • Illness Prediction: Uses TF–IDF, BM25, and a Logistic Regression classifier to analyze symptoms and predict related illnesses with user feedback.
  • Multi-Tab Navigation: Dedicated tabs for herbal data, deep learning searches, and general web queries.
  • Real-Time Logging & Menus: Built-in logging provides instant feedback and context menus enable quick copy-paste.

Technologies Used: Python, Tkinter, CSV, JSON, requests, BeautifulSoup, socket, subprocess, PIL, ImageTk, deep_translator, NLTK, scikit-learn, NumPy, regular expressions, threading

Visuals: The interface features an expandable tree view, interactive search panels, and a dynamic image grid. Screenshots available upon request.
